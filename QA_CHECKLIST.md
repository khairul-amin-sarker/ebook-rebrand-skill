# PDF-Native Ebook Rebrand QA Checklist

## Structure
- [ ] Page count correct
- [ ] Page dimensions match source
- [ ] No accidental blank/duplicate pages
- [ ] Page order preserved

## Typography
- [ ] Exact/approved fonts used
- [ ] Bengali shaping correct
- [ ] Font sizes consistent
- [ ] Line spacing consistent
- [ ] Unchanged content keeps source line wrapping as closely as possible

## Branding
- [ ] Old logo removed
- [ ] Old brand text removed
- [ ] Old watermark removed
- [ ] Old website/domain removed
- [ ] Old copyright removed
- [ ] New brand name exact case everywhere
- [ ] New year correct everywhere
- [ ] New title correct
- [ ] Written-by/publisher line correct
- [ ] PDF metadata updated

## Watermark
- [ ] Logo present if required
- [ ] Brand text present if required
- [ ] Correct capitalization
- [ ] Correct opacity
- [ ] Correct angle
- [ ] Correct size and position
- [ ] Does not reduce readability

## Infographics
- [ ] Vector/native PDF where required
- [ ] Exact colors preserved
- [ ] Geometry preserved
- [ ] Text labels accurate
- [ ] No unwanted AI-generated/raster replacements

## Visual Match
- [ ] Header alignment
- [ ] Divider alignment
- [ ] Text box alignment
- [ ] Heading placement
- [ ] Infographic placement
- [ ] Footer placement
- [ ] Background color consistent

## Mobile Readability
- [ ] Body text readable on phone
- [ ] Infographic labels readable
- [ ] No clipping
- [ ] Contrast sufficient
- [ ] Watermark subtle

## Legacy Brand Search
Search the PDF text/object layer for every legacy brand/domain term.
- [ ] 0 unwanted matches remain
